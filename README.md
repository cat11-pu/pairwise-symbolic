# symbolic

一个只用 Python 标准库实现的符号表达式化简内核实验项目。
不读时钟、不做 I/O、不用随机数、不起线程，同样的输入永远得到同样的输出。

## 表达式

表达式是嵌套元组，一共六种：

    ("num", 3)              整数常量
    ("sym", "x")            可交换的符号，小写名字
    ("nc", "A")             非交换的原子，大写名字，例如矩阵
    ("add", (a, b, ...))    两项以上的和
    ("mul", (a, b, ...))    两项以上的积
    ("pow", base, k)        底数的 k 次幂，k 是非负整数

文本写法与元组一一对应：`2*(x + 1)^2` 里的 `x` 是小写名字、`A` 是大写名字；指数
只能写成十进制非负整数；`-` 既可以是一元负号也可以是减法；名字都是一个字母。

## 接口

`symbolic/core.py` 提供：

- `parse(text)`：把文本读成表达式，原样保留括号与写法；
- `simplify(expression)`：化简成规范形式；
- `to_text(expression)`：把表达式渲染回文本；
- `SymbolicError`：文本写错、节点形状不对、指数不合法时抛出；`parse` 收到非字符串
  时抛 `TypeError`。

## 规范形式

化简之后：

- 括号摊平：乘积里出现和式就按分配律乘开，积中积、和中和摊平；已经摊平的乘积里
  不会再留下和式因子；
- 常量折叠：和式里的常数并成一项、放在最后；乘积里的常数并成一个整系数、放在最前；
  系数 1 省略，系数 0 让整个积变成 0；
- 同类项合并：每个加项看成「整系数 × 骨架」，骨架相同的项系数相加，系数为 0 的项消失；
- 幂：乘积里同底数的因子并成一个幂、指数相加；幂套幂的指数相乘；`(x*y)^2` 摊成
  `x^2*y^2`；`x^1` 记作 `x`，`x^0` 记作 `1`；
- 顺序：加项按次数从高到低、同次数按文本升序，常数项落在最后；乘积里整系数在最前，
  其余因子在各自区段内按文本升序。次数指一个加项里各个名字的幂次之和（整系数不算，
  和式的幂按指数乘进去）；
- 非交换保护：任何因子都不得跨过非交换原子，乘积被原子切成若干区段，只有整系数可以
  被提到最前；含非交换原子的乘积不摊开它的幂，`(A*B)^2` 保持原样而不是 `A^2*B^2`；
  相邻的同底数幂照旧合并，`A^2*A^3` 就是 `A^5`。

结果唯一：不含非交换原子的表达式，任何等价的书写（因子先后、括号怎么加、常量写成
`2*3` 还是 `6`）都收敛到同一棵树。`0^0`、`x^y`、`x^-1` 一律抛 `SymbolicError`，
不静默返回。

## 目录

    symbolic/__init__.py   对外导出
    symbolic/core.py       解析、化简与渲染内核
    tests/test_core.py     验收测试

## 怎么跑测试

在项目根目录执行：

    python3 -m unittest discover -s tests -v

Windows 上用任意 Python 3 解释器执行同一条命令即可，例如：

    C:/Users/Administrator/AppData/Local/Programs/Python/Python313/python.exe -m unittest discover -s tests -v
